01 / EL ECOSISTEMA

No es una distro
para todo.

Snakey separa dos mundos que no deben confundirse.

Las consolas clásicas ejecutan ROMs homebrew nativas diseñadas para su procesador y hardware. Snakey Linux, en cambio, está reservado para equipos capaces de ejecutar un kernel Linux real. Así mantenemos compatibilidad y expectativas honestas.

04 / PRIMERA PRUEBA

Tu primera ROM.
En RetroArch.

La primera prueba pública estará centrada en NES NROM-256. Cuando haya una ROM publicada, podrás descargarla y abrirla desde RetroArch.

Obtener RetroArch ↗
GUÍA RÁPIDA / NESPREPARADO
  1. Consigue la ROMDescarga el archivo .nes desde una publicación oficial de Snakey.
  2. Instala un núcleo NESEn RetroArch, actualiza los núcleos y elige uno compatible con NES/Famicom.
  3. Abre el contenidoVe a Cargar contenido, selecciona el .nes y elige el núcleo.
  4. Prueba el menúUsa la cruceta para navegar, A para seleccionar y B para volver.

Importante: el artefacto de CI es una compilación de prueba. La prueba visual en RetroArch se confirmará por separado; compilar correctamente no demuestra todavía que el menú se vea o responda correctamente en un emulador.
